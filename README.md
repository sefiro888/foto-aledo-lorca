# Foto Aledo Lorca · web de demostración

Propuesta de rediseño (no oficial) para Foto Aledo, estudio fotográfico de Javi Aledo en Lorca desde 1920, especialistas en fotografía de recién nacido.

Web estática: 12 páginas HTML, CSS y JavaScript sin dependencias. Las fotografías pertenecen a Foto Aledo y se usan solo para esta demostración.
